# fripuck2
Monorepo for all the stack necessary for the robotics course of the university of Fribourg. 

This project aims to modify the current implementation of the firmware and API used by the university of Fribourg to work with the E-puck2 robots, built by [GCtronic](https://www.gctronic.com/doc/index.php/e-puck2) and designed by the [EPFL](https://www.epfl.ch/labs/mobots/robots-technologies/e-puck2/).
Its objectives are to:
1. Provide the option to program the robot on-board without having to modify the firmware 
2. Improve the transmission of data from the robot to the remote client.
